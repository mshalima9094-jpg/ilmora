# ILMORA — Gmail লগইন + মাসিক সাবস্ক্রিপশন সংস্করণ

**হোস্ট:** GitHub Pages · **নিরাপত্তা:** Firebase (Auth + Firestore Rules) · **ফাইল স্টোরেজ:** Cloudflare (R2 + Worker, ঐচ্ছিক)

## অ্যাপের ধাপ (ব্যবহারকারীর চোখে)
1. **Gmail + পাসওয়ার্ড** দিয়ে লগইন/নিবন্ধন (মোবাইল নম্বর লগইন বাদ)।
2. Gmail **যাচাই** (Firebase-এর পাঠানো মেইলের লিংক) — যাচাই ছাড়া কিছুই খোলে না।
3. **মাসিক পেমেন্ট পাতা**: তিন প্যাকেজ + বিকাশ/নগদ/রকেট নম্বর → টাকা পাঠিয়ে TrxID দিন।
4. Super Admin পেমেন্ট মিলিয়ে অনুমোদন দিলে অ্যাপ **৩০ দিনের জন্য** চালু। মেয়াদ শেষ হলে আবার এই পাতায় আটকে যায়।

## নিরাপত্তা ব্যবস্থা (সবই সার্ভারে — `firestore.rules`)
- **Gmail যাচাই** না হলে কোনো ডেটা পড়া/লেখা নেই।
- **মেয়াদ/অনুমোদন সার্ভারে প্রয়োগ হয়**: মাদরাসা `active` না থাকলে বা মেয়াদ শেষ হলে রেকর্ড পড়া-লেখা দুটোই বন্ধ। ফোনের ঘড়ি বা জাভাস্ক্রিপ্ট বদলে এড়ানো যায় না।
- এক মাদরাসা অন্যের ডেটা দেখতে পারে না; শিক্ষক/শিক্ষার্থীর সীমিত অধিকার আগের মতোই।
- প্যাকেজ, মেয়াদ, স্ট্যাটাস শুধু Super Admin বদলাতে পারে।
- **একই TrxID দুইবার জমা হয় না** (পেমেন্ট ডকুমেন্টের আইডিই TrxID)।
- পাসওয়ার্ড ভুললে Firebase-এর ইমেইল রিসেট; অ্যাডমিনও ইউজারের Gmail-এ রিসেট লিংক পাঠাতে পারেন।

## চালু করার ধাপ
**১. Firebase Console**
1. Authentication → Sign-in method → **Email/Password চালু**।
2. Authentication → Settings → **Authorized domains**-এ `আপনার-নাম.github.io` যোগ করুন।
3. Authentication → Templates → ইমেইল যাচাই/পাসওয়ার্ড রিসেটের বার্তা বাংলা করুন (ঐচ্ছিক)।
4. Firestore → Rules-এ `firestore.rules` পেস্ট করে **Publish**।
5. Google Cloud Console → APIs & Services → Credentials → আপনার Browser API key → **HTTP referrers** সীমা: `https://আপনার-নাম.github.io/*`।
6. অ্যাপে নিজের Gmail দিয়ে নিবন্ধন → Gmail যাচাই → স্ক্রিনে আপনার **UID** দেখাবে (ভিতরে "প্ল্যাটফর্ম মালিক?" অংশ)। Firestore-এ `superAdmins` কালেকশনে ওই UID দিয়ে ডকুমেন্ট বানান (ফিল্ড `name`)। লগআউট → লগইন করলেই Super Admin প্যানেল।

**২. GitHub Pages:** এই ফোল্ডারের ফাইলগুলো (`tests/`, `cloudflare-worker/`, `README*`, `firestore.rules`, `firebase.json` বাদে রাখলেও ক্ষতি নেই) রিপোজিটরিতে আপলোড → Settings → Pages → Branch `main` / root।

**৩. Cloudflare ফাইল স্টোরেজ (ঐচ্ছিক):** `cloudflare-worker/wrangler.toml`-এ `ALLOWED_ORIGIN` বদলে `wrangler deploy`; R2 বাকেট `ilmora-files`। তারপর `saas.js`-এর শুরুতে `CF_URL`-এ Worker-এর ঠিকানা বসান। (R2 চালু করতে Cloudflare-এ পেমেন্ট মেথড লাগে।)

## Rules Playground-এ অবশ্যই পরীক্ষা করুন (Publish-এর আগে)
- Gmail-যাচাই-না-হওয়া ইউজার → সব অস্বীকার।
- অ্যাডমিন, মেয়াদ বাকি → রেকর্ড পড়া/লেখা ঠিক; `expiresAt` অতীতে করলে → অস্বীকার।
- অ্যাডমিন নিজের `plan`/`status`/`expiresAt` বদলাতে গেলে → অস্বীকার।
- ভিন্ন মাদরাসার ইউজার → অস্বীকার; শিক্ষার্থী অন্য শিক্ষার্থীর `pub` ডকুমেন্টে → অস্বীকার।
- একই `tx_b_<TrxID>` দ্বিতীয়বার create → অস্বীকার; ভুল `amt`/ফরম্যাট → অস্বীকার।

## সততার সাথে — যা এখনো বাকি / সীমাবদ্ধতা
- **আসল Firebase-এ পরীক্ষা এখানে সম্ভব হয়নি।** `tests/e2e.py` নকল Firebase সার্ভারের বিরুদ্ধে ব্রাউজারে ৪৪টি পরীক্ষা চালায় (সব পাস), কিন্তু **Firestore Rules চলে না**। তাই উপরের Playground পরীক্ষা বাধ্যতামূলক। বিশেষ করে `payments`-এর `where t == ...` লিস্ট কুয়েরি আসল Firebase-এ একবার দেখে নিন।
- **পেমেন্ট ম্যানুয়াল।** Super Admin নিজে বিকাশ/নগদ/রকেটের অ্যাপে TrxID ও টাকার পরিমাণ মিলিয়ে অনুমোদন দেবেন। অ্যাপ নিজে টাকা যাচাই করে না। (স্বয়ংক্রিয় করতে পেমেন্ট গেটওয়ের API ও সার্ভার লাগবে।)
- **শিক্ষার্থী/ইউজার সংখ্যার সীমা ক্লায়েন্টে প্রয়োগ হয়**; রুলসে গণনা সম্ভব নয়। মেয়াদ ও অ্যাক্সেস কিন্তু সার্ভারে প্রয়োগ হয়।
- **শুধু Gmail:** নিবন্ধন ও ইউজার যোগে `@gmail.com` বাধ্যতামূলক (`saas.js`-এ `GMAIL_ONLY = false` করলে যেকোনো ইমেইল)। শিক্ষার্থীদের Gmail না থাকলে এটি সমস্যা হতে পারে।
- **ইউজার "মুছুন" করলে** তার Firebase অ্যাকাউন্ট থেকে যায় (ক্লায়েন্ট থেকে মোছা যায় না) — একই Gmail আবার যোগ করা যাবে না। তাই "নিষ্ক্রিয়" ব্যবহার করুন।
- অফলাইনে ফোনে থাকা ডেটা মেয়াদ শেষের পরও ওই ফোনে থাকে; নতুন সিঙ্ক/ডেটা আর হয় না।
- Cloudflare Worker **কোড লেখা আছে কিন্তু পরীক্ষা করা হয়নি** এবং অ্যাপের কোনো ছবি/ফাইল ঘরের সাথে এখনো জোড়া হয়নি। এখন ছবি সংকুচিত হয়ে রেকর্ডের ভেতরেই থাকে। জোড়ার সহায়ক ফাংশন `FBX.cfPut/cfGet/cfDel` তৈরি আছে।
- Firebase-এর যাচাই/রিসেট মেইল অনেক সময় **স্প্যাম ফোল্ডারে** যায়। বাংলায় বার্তা বদলে ও কিছুদিন ব্যবহারে উন্নতি হয়।
- Spark কোটা: দিনে ২০ হাজার লেখা/৫০ হাজার পড়া; ব্যবহারকারী বাড়লে Blaze লাগতে পারে।
- বট/স্প্যাম নিবন্ধন ঠেকাতে ভবিষ্যতে Firebase App Check যোগ করা ভালো।
